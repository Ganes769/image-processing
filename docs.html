Image Processing API

Local docs for upload and transform. Compare these shapes to batch_test_log.txt.

Upload

POST /api/images/upload

Protected. multipart field name: image or file. Types: jpg, png, webp.

Success 201

{
  "message": "Image uploaded successfully",
  "image": { "id": 3, "url": "...", "width": 800, "height": 600 }
}

Errors

StatusWhenExample body
400Not jpg/png/webp{"message":"Only jpg, png, webp images are allowed"}
400Wrong field name{"message":"Unexpected field","expected_fields":["image","file"]}
401Missing/invalid JWT{"message":"Access denied. No token provided."}

Transform

POST /api/image/:id/transform

Protected. :id is the original image id.

{
  "transformation": {
    "resize": { "width": 300, "heigth": 300 },
    "format": "webp"
  }
}

Success 200

{
  "id": 1,
  "url": "...",
  "format": "webp",
  "width": 300,
  "height": 300
}

Errors

StatusWhenExample body
401Missing/invalid JWT{"message":"Unauthorized"}
404Image id not found{"message":"image not found"}
502Could not fetch original{"message":"Failed to fetch image"}
500Transform failed{"message":"Server error"}

Supported formats: jpeg, jpg, png, webp, avif.
